# Omar Mustafa – Frontend Developer Portfolio

A personal portfolio website presenting my profile, frontend development skills, selected projects, and professional background.

## Sections
- Introduction and about me
- Technical skills and technologies
- Selected projects
- Experience and testimonials
- Contact information

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Google Fonts

## Run Locally
1. Clone this repository.
2. Open `Omar-Mustafa-Portifolio/index.html` in your browser.

## Project Structure
The portfolio source is inside `Omar-Mustafa-Portifolio/`. Stylesheets, JavaScript, and image assets are organized under `assets/`.
